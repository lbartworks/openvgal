How Preview Works

  • Preview loads the gallery structure in the 3D viewer
  • Images will display if they exist in the expected paths on this server
  • For example: gallery "landscapes" looks for images at /landscapes/image.jpg

Deployment

  1. Click Download Complete ZIP
  2. Extract the ZIP to your web server
  3. Add your image folders with matching names
  4. Open index.html in a browser (or serve with any web server)
